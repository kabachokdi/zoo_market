# Интернет-магазин сети магазинов Зоология

## Заказчик
Cеть магазинов товаров для животных - "Зоология", находятся на ДВ, 20 магазинов в крупных городах.
Планируют расширяться в РФ на горизонте 2х лет.
Имеют небольшой опыт работы с интернет маркетингом, хотят расширяться.
Есть _инвестор_, риск соскока - _небольшой_.
## Заказ
Требуется создать маркетплейс для их бизнеса.
Сперва сайт, потом мобильное приложение.
Облако.
__Срок__ - 2 года. __Бюджет__ - 15-20 млн руб.
## ЦА
- Владельцы домашних животных
    -  покупка осн продукции (корм, товары, услуги), запись к ветеренару, донаты приютам
- Заводчики
    -  любители: размещение объявлений, покупка осн продукции
    - профи: то - же, продвижение объявлений, реклама, оптовая покупка, услуги доставки
- те, кто хотят купить животное
    - просмотр объявлений по продаже
- Ветклиники и приюты
    - оформление партнёрки
- приюты
    - сбагривание животных в хорошие руки
  

# Требования и примерные сроки
## Функционал
### Основной

- Коммерция
    - продажа корма и сопутствующих товаров для животных
        - базовый способ получения товара - самовывоз
        - базовый способ оплаты - онлайн
        - распределение товаров по тегам
        - карта магазинов, интеграция с сервисом карт (яндекс, гугл, 2гис)
   - Торговля породистыми животными, как маркетплейс
        - Создание и оформление обьявлений типа авито
    - Запись в ветеринарку по партнёркам
    - услуги для животных
- Благотворительность: донаты приютам по типу подписки
- Интеграция с существ. системой 1С
   - Платежи
   - Накладные
   - Товары
### Дополнительно
- Система лояльности
- Рекомендательная система - персонифицированный подбор товаров
- интеграция с курьерской службой для доставки товаров
- Платёжные службы - разные
- поиск по сайту
## Сроки разработки
1. 0-3 месяцы
   - Продажа товаров и корма
2. 3-6
    - торговля животными и донаты
3. 6-12
    - интеграция с ветеренарами
4. 12 - 18
   - услуги для животных
5. до конца - доп функционал
